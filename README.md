# Faymas Prompt Checklist

A practical checklist for adapting AI image prompts before generating an image.

This repository mirrors the reusable checklist published with the Faymas Prompt Guide at https://faymaspromptguide.com/.

## Included resources

- `faymas-prompt-checklist.md` — readable Markdown version
- `faymas-prompt-checklist.txt` — plain-text version
- `prompt-category-reference.csv` — category reference table

## How to use

Start with the subject and relationship, then adjust the setting, clothing, pose, lighting, and visual style. Change one instruction at a time so you can see which edit improves the result.

## Checklist categories

- Couple portrait
- Family portrait
- Cinematic portrait
- Realistic photo edit
- Father-and-child image
- Social-media portrait
